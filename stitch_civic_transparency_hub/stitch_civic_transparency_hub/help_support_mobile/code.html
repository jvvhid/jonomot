সাধারণ প্রশ্নাবলী

রিপোর্ট জমা দিতে, নিচের ন্যাভিগেশন বার থেকে 'Report' বাটনে ক্লিক করুন। ফর্মে আপনার সমস্যা বিস্তারিত লিখুন এবং প্রয়োজনে ছবি যুক্ত করে 'জমা দিন' বাটনে ক্লিক করুন।
আপনার প্রোফাইল সেকশনে গিয়ে 'আমার রিপোর্ট' অপশনে ক্লিক করলে আপনি আপনার সমস্ত রিপোর্টের বর্তমান অবস্থা (যেমন: পেন্ডিং, প্রসেসিং, সমাধানকৃত) দেখতে পারবেন।
লগইন পেজে 'পাসওয়ার্ড ভুলে গেছেন?' লিঙ্কে ক্লিক করুন। আপনার নিবন্ধিত ইমেইল বা ফোন নম্বর প্রদান করলে একটি রিসেট লিঙ্ক বা ওটিপি পাঠানো হবে।
